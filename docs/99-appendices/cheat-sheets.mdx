## Percentiles

A percentile is the value below which a given share of samples falls. Use them for latency, not averages. Tools may calculate percentiles in slightly different ways, so compare runs made with the same tool.

| Name | Meaning | Use it for |
|---|---|---|
| p50 (median) | Half of requests are faster | Typical experience |
| p90 | 90% of requests are faster | Early warning for a slow tail |
| p95 | 95% of requests are faster | Common SLO target |
| p99 | 99% of requests are faster | Worst-case experience for busy endpoints |

See [Performance metrics](/performance-fundamentals/performance-metrics).

## HTTP status codes used by TaskFlow

| Code | Name | Where TaskFlow returns it |
|---|---|---|
| 200 | OK | Login, read, list, update and assign succeed |
| 201 | Created | `POST /api/tasks` and `POST /api/projects` succeed |
| 204 | No Content | `DELETE /api/tasks/{id}` succeeds |
| 401 | Unauthorized | Missing or invalid bearer token, or wrong login password |
| 403 | Forbidden | Caller is not a member of the task's project |
| 404 | Not Found | Task or project does not exist |
| 409 | Conflict | Status move is not allowed by the status flow |
| 422 | Unprocessable Content | Validation fails (title length, priority) or assignee is not a project member |

Note: a non-member gets 403 for an existing task and 404 for a missing one. Those two answers reveal which task IDs exist. Test it as a security check.

## ECS and ALB metric names

| Namespace | Metric | Level | What it shows |
|---|---|---|---|
| `AWS/ECS` | `CPUUtilization` | Service | Percent of reserved CPU in use |
| `AWS/ECS` | `MemoryUtilization` | Service | Percent of reserved memory in use |
| `AWS/ECS` | `CPUReservation` | Cluster (EC2 tasks only) | Percent of cluster CPU reserved |
| `AWS/ECS` | `MemoryReservation` | Cluster (EC2 tasks only) | Percent of cluster memory reserved |
| `ECS/ContainerInsights` | `CpuUtilized` | Service, task | CPU units used (not percent) |
| `ECS/ContainerInsights` | `MemoryUtilized` | Service, task | Memory in use, in MiB |
| `ECS/ContainerInsights` | `RunningTaskCount` | Service | Tasks in RUNNING state |
| `ECS/ContainerInsights` | `DesiredTaskCount` | Service | Tasks the service wants |
| `ECS/ContainerInsights` | `PendingTaskCount` | Service | Tasks waiting to start |
| `ECS/ContainerInsights` | `RestartCount` | Service, task | Container restarts (restart policy only) |
| `AWS/ApplicationELB` | `RequestCount` | Load balancer | Requests the load balancer routed to targets |
| `AWS/ApplicationELB` | `TargetResponseTime` | Target group | Seconds from request sent to response headers received (use percentiles) |
| `AWS/ApplicationELB` | `HTTPCode_Target_5XX_Count` | Target group | 5XX responses generated by your app |
| `AWS/ApplicationELB` | `HTTPCode_ELB_5XX_Count` | Load balancer | 5XX responses generated by the load balancer |
| `AWS/ApplicationELB` | `HealthyHostCount` | Target group | Healthy targets |
| `AWS/ApplicationELB` | `UnHealthyHostCount` | Target group | Unhealthy targets |
| `AWS/ApplicationELB` | `RequestCountPerTarget` | Target group | Average requests per target |

Sources: [ECS available metrics](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/available-metrics.html), [Container Insights metrics for ECS](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/Container-Insights-metrics-ECS.html), [ALB CloudWatch metrics](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/load-balancer-cloudwatch-metrics.html). Container Insights metrics cost extra. The Container Insights list above is a subset.
