Every link here was opened on 2026-11-06. Repo facts come from the GitHub repo page and the GitHub release API. Company-usage claims are classified, and anything we could not check is listed at the end.
</TLDR>

## What and why

A handbook page is only as good as its sources. This page lists what we opened, what each source supports, and what happened when we opened it. If a link here stops working, the fact it supports is no longer verified.

## How it works

For each tool, we opened the repo page (licence, description, language, releases) and the GitHub release API (latest release tag and publish date). Where a claim needed more than the repo, we opened the project's docs. Search results were used only to find leads. We did not count a search snippet as a source.

## What we could not verify

- Licence and release date of the Postman CLI; parallelism and CI details for REST Assured, Postman CLI and Selenium; the provider side of Pact on TaskFlow; company use of Selenium, Cypress, REST Assured, Postman CLI and pact-python.
- Company production use for Playwright, Playwright MCP, Browser Use, Appium, DeepEval, Ragas, Langfuse (beyond the third-party claim above), EvoMaster, Keploy, Locust, k6, Artillery and JMeter.
- Language and CI integrations for Appium, Ragas, Langfuse, Keploy, Artillery and the MCP servers, where the table says "not verified".
- The EvoMaster technique beyond the repo's "AI-driven" description, because its site did not load.
- The full OWASP list beyond LLM01, because the page text fetched did not include it.
- The Appium main release, because the GitHub API returned a sub-package tag.
- The JMeter latest version, because the GitHub mirror's latest release is from 2024.
- Locust body docs, because the docs page did not render its text.

Facts we could not verify are left out of the chapters, or marked "not verified" in the tool directory.
